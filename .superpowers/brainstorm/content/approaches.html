选择技术架构方案

三种方案都能实现目标，各有侧重

A

纯前端 SPA + 边缘函数代理

Vue 3 纯前端应用 + Vercel/Netlify Function 代理讯飞 API。最轻量，部署最简单，一个命令上线。

优点

  • 部署最简单，免费托管
  • 前端即全栈，心智负担低
  • Serverless 自动扩缩

缺点

  • 依赖第三方平台
  • 冷启动有延迟
B

Nuxt 3 全栈框架（推荐）

Vue 3 生态的全栈框架，前端 + API 路由在一个项目中统一管理。最符合这个场景。

优点

  • 前后端统一项目，开发体验好
  • API 路由开箱即用，代理讯飞 API
  • Vue 生态最佳实践，文件即路由

缺点

  • 需要 Node.js 运行环境
  • 相比纯前端多一层概念
C

前后端分离

Vue 3 前端 + Express/Fastify 独立后端，职责清晰，适合后续扩展。

优点

  • 前后端独立部署和扩展
  • 扩展性最好，适合团队协作

缺点

  • 项目结构更复杂
  • 需要协调两个服务
